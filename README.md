# Task Management Application

A full-stack task management web application with user authentication.

## Features
- User Registration & Login
- Create and Delete Tasks
- Responsive Design
- JWT Authentication

## Tech Stack
- React.js
- Node.js/Express
- JWT for auth

## How to Run
1. Clone the repo
2. Run `cd backend && npm install && node index.js`
3. Run `cd frontend && npm install && npm start`
